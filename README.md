# Проекты с курса по тестированию ПО

Этот репозиторий содержит примеры моих работ, выполненных в рамках курса по тестированию программного обеспечения. Здесь вы найдете тестовую документацию, примеры SQL-запросов.

## Структура репозитория


  - `test_documentation.md` — пример составления тестовой документации.
  - `sql_task.sql` — примеры SQL-запросов.
  - `qa_db.md` — логические модели базы данных.
- **README.md** — описание проекта.

## Примеры работ

### 1. Тестовая документация
В файле [`test_documentation.md`](/test_documentation.md) представлены примеры составления тестовой документации, включая:
- Тестовые сценарии.
- Чек-листы.
- Баг-репорты.

### 2. Примеры SQL-запросов
В файле [`sql_task.sql`](/sql_task.sql) вы найдете примеры SQL-запросов, которые я использовала в процессе обучения:
- Простые SELECT-запросы.
- Фильтрация данных с помощью WHERE.
- JOIN-запросы для работы с несколькими таблицами.
- Группировка и агрегация данных.

### 3. Изображения и скриншоты
В папке [`/images`](/images) собраны скриншоты, иллюстрирующие процесс тестирования, примеры работы с инструментами и результаты выполнения тестов.
